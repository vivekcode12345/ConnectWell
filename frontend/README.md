# ConnectWell Frontend

React + Vite + Tailwind UI for ConnectWell.

## Setup
```bash
npm install
cp .env.example .env
```

## Development
```bash
npm run dev
```

## Environment Variables
- `VITE_API_BASE_URL`

## Scripts
- `npm run dev` - Start Vite dev server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
